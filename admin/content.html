Global Content

  • Changes are stored in browser LocalStorage.
  • Main app pages can read these values.
  • Existing pages should use the global content engine.
  • Save after making changes.

Supported Content

App name, tagline, hero, motivation, announcement, About, owner, contact, address, footer and version.

Content changes are stored locally in this browser. For a real multi-device admin system, connect this manager to a server/database.
