CSS Manager Guide

How custom styles work

Example:

You can create a style like:

.quick-item{ border-radius:25px; transform:translateY(-2px); }

Save it as a custom CSS block. Enable the block and it can be applied through the global app engine.
This browser-based CSS Manager does not physically modify your original style.css. For permanent deployment, export the CSS and add it to your deployed stylesheet or connect it to the app's custom CSS engine.
